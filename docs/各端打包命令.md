# 各端打包命令速查

> 正式 / 测试环境对照见：`docs/测试环境搭建-guokegames.md`  
> H5 支付页部署细节见：`docs/h5-deploy-baota.md`

---

## 1. Web 管理后台（`delta-admin-ui`）

```bash
cd delta-admin-ui
npm install          # 首次或依赖变更时

# 正式环境 → guokegames.online
npm run build

# 测试环境 → test.guokegames.online
npm run build:staging
```

| 环境 | 产物目录 | 常见服务器路径 |
|------|----------|----------------|
| 正式 | `dist/` | `/www/wwwroot/dist` |
| 测试 | `dist/` | `/www/wwwroot/dist-test` |

本地开发：`npm run dev`

---

## 2. Java 后端（`delta-game`）

```bash
cd delta-game
mvn clean package -DskipTests -pl delta-admin -am
```

产物：`delta-admin/target/delta-admin.jar`

| 环境 | 启动参数 | 常见 jar 路径 | 端口 |
|------|----------|---------------|------|
| 正式 | `--spring.profiles.active=prod` | `/www/wwwroot/delta-admin.jar`（以服务器实际为准） | 8080 |
| 测试 | `--spring.profiles.active=test` | `/www/wwwroot/delta-admin-test.jar` | 8081 |

配置文件：

- 正式：`delta-admin/src/main/resources/application-prod.yml`
- 测试：`delta-admin/src/main/resources/application-test.yml`

---

## 3. 小程序端 H5（`delta-mp`）

整站 H5（含用户端页面与支付页）共用同一条打包命令：

```bash
cd delta-mp
npm install          # 首次或依赖变更时
npm run build:h5
```

| 项 | 说明 |
|----|------|
| 产物 | `delta-mp/dist/build/h5/`（须含 `index.html` + `assets/` 整目录上传） |
| 服务器目录 | `/www/wwwroot/mp-h5` |
| 站点路径 | `https://guokegames.online/h5/` |

本地调试：`npm run dev:h5`

---

## 4. H5 支付页

**无单独打包命令。** 支付页路由为 `pages/order/h5pay`，打在 H5 包内。

```bash
cd delta-mp
npm run build:h5
```

支付页地址示例：

```text
https://guokegames.online/h5/#/pages/order/h5pay
```

后端配置项：`pay.kf.h5-pay-base-url`（如 `https://guokegames.online/h5/#/pages/order/h5pay`）  
部署步骤详见：`docs/h5-deploy-baota.md`

---

## 5. 微信小程序本体（非 H5）

```bash
cd delta-mp
npm install
npm run build:mp-weixin
```

| 项 | 说明 |
|----|------|
| 产物 | `delta-mp/unpackage/dist/build/mp-weixin`（以本机构建输出为准） |
| 上传 | 用微信开发者工具打开产物目录后上传 |

本地调试：`npm run dev:mp-weixin`

> 说明：部分文档曾写 `build:mp-weixin:staging`，当前 `delta-mp/package.json` **未定义**该脚本；小程序正式构建请使用 `build:mp-weixin`。

## 一览表

| 端 | 目录 | 正式打包 | 测试打包 |
|----|------|----------|----------|
| Web 管理后台 | `delta-admin-ui` | `npm run build` | `npm run build:staging` |
| Java | `delta-game` | `mvn clean package -DskipTests -pl delta-admin -am` | 同左，启动用 `test` profile |
| 小程序 H5 / 支付页 | `delta-mp` | `npm run build:h5` | 本地可用 `npm run dev:h5` |
| 微信小程序 | `delta-mp` | `npm run build:mp-weixin` | `npm run dev:mp-weixin` |
